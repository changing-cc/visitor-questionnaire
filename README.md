# 访客问卷

冷白色的 15 题互动问卷，适配手机、平板和电脑浏览器。

填写全部题目后点击「提交问卷」：

- 第一句「姓名，谢谢你的回答。」每 100 毫秒显示一个字符。
- 第一句完整显示后停顿 2 秒。
- 第二句「不对……部位，谢谢你的回答。」以相同速度逐字显示；多选部位用顿号连接。
- 第二句使用深红晕染效果，文字完整显示后出现血滴。

答案仅保存在填写者浏览器的本地存储中；页面没有收集答案的服务器接口。可以返回修改、清空回答或下载自己的答案。

## GitHub Pages 发布

在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，选择 `main` 分支和 `/ (root)`，保存后等待部署完成。入口文件为 `index.html`，无需安装依赖或构建。

使用部署后的网页链接填写。iPad 文件预览不适合作为互动问卷的打开方式。

本问卷为虚构游戏内容，请勿代入现实。
